# BennuIDE

**BennuIDE** es un entorno de desarrollo integrado (IDE) profesional y multiplataforma diseñado específicamente para la creación de videojuegos con el lenguaje **BennuGD2**.

Basado en el motor de código abierto **Code-OSS**, BennuIDE ofrece una experiencia de desarrollo completa, moderna y extensible.

---

## 🌟 Características Principales

- 🎮 **Soporte Oficial de BennuGD2**:
  - Resaltado de sintaxis avanzado y formateador de código.
  - Servidor de Lenguaje (**LSP**) con autocompletado inteligente, diagnósticos en tiempo real, definiciones y *hover*.
  - Compilación y ejecución integrada (`bgdc` y `bgdi`) con detección automática de errores y acceso directo a la línea de código.
  - Depurador interactivo línea a línea (**DAP**) con puntos de interrupción (breakpoints), inspección de variables y pila de llamadas.
- 🎨 **Temas Visuales Cuidados**:
  - **BennuIDE Dark**: Basado en *One Dark Pro Night Flat*.
  - **BennuIDE Light**: Basado en *PowerShell ISE*.
- 🖼️ **Editor Visual de Archivos FPG**:
  - Inspección, previsualización, edición y gestión de colecciones de sprites (`.fpg`).
  - Posicionamiento y edición visual de puntos de control (control points).
  - Importación y exportación de imágenes PNG/BMP.
- 🔤 **Editor / Generador de Fuentes FNT y FNX**:
  - Generación de fuentes bitmap a partir de archivos TrueType (`.ttf`/`.otf`).
  - Soporte para formato moderno **FNX** (BennuGD2) y formato legado **FNT** (DIV2).
  - Configuración de antialiasing, grosor, color, sombras y transparencias.
- 🤖 **Asistente de IA Integrado**:
  - Panel de asistencia de código contextualizado con la API y sintaxis de BennuGD2.
- 🛠️ **Herramientas de Desarrollo**:
  - Control de versiones integrado (**Git**).
  - Terminal integrada multiplataforma.
  - Sistema de extensiones compatible con la comunidad.
